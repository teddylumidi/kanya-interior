# Kanya Interior

A portfolio website for Kanya Interior — premium interior design, renovation & construction services in Nairobi, Kenya.

## Stack
- Static HTML (`index.html`) + images served by Express.js (`server.js`)
- No build step required
- Node.js 20

## How to run
```
npm install
npm start
```
The server listens on port 3000.

## Project structure
```
index.html      — single-page portfolio site (all HTML, CSS, JS inline)
server.js       — Express static file server
images/         — 39 project photos (1.jpeg – 39.jpeg) + logo.png
package.json
```

## User preferences
- Image labels must accurately describe what is actually visible in each photo.
